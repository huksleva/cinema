# Кинотеатр

Учебный проект команды 1 на платформе **1С:Предприятие 8.3**. Версия **1.2.2** включает панель управления, рабочие места закупщика и кассира, учёт товаров и резервов кинобара. В конфигурации также есть касса билетов, справочники фильмов, залов, мест и сеансов.

[Актуальная документация в GitHub Wiki](https://github.com/huksleva/cinema/wiki) · [Сайт с документацией версии 1.1.0](https://huksleva.github.io/cinema/)

## Запуск из исходников

Понадобятся Windows, Git, PowerShell 7 и платформа 1С:Предприятие. Проект рассчитан на учебную сборку **8.3.27.1688**.

```powershell
git clone https://github.com/huksleva/cinema.git
Set-Location 'cinema\Кинотеатр'
.\scripts\Build.ps1
.\scripts\Test.ps1
```

`Build.ps1` загружает конфигурацию в отдельную файловую базу `build/infobase`. `Test.ps1` добавляет демонстрационные данные кинобара и запускает проверки. Откройте `Открыть Кинотеатр.cmd` для режима 1С:Предприятие или `Конфигуратор.cmd` для разработки. Если получена готовая база, положите её файл `1Cv8.1CD` в `Кинотеатр/database/`.

Для установки платформы в нестандартном каталоге используйте параметр `-Platform`. Порядок сборки и выгрузки описан в [инструкции к сценариям](Кинотеатр/scripts/README.md).
