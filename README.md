# Кинотеатр

Учебный проект на платформе **1С:Предприятие 8.3** для учета товаров кинобара. Конфигурация ведет поступления, продажи и розничные цены, контролирует остатки и формирует отчеты по остаткам и выручке.

## Запуск из исходников

Понадобятся Windows, Git, PowerShell 7 и платформа 1С:Предприятие. Проект рассчитан на учебную сборку **8.3.27.1688**.

```powershell
git clone https://github.com/huksleva/cinema.git
Set-Location 'cinema\Кинотеатр'
.\scripts\Build.ps1
.\scripts\Test.ps1
```

`Build.ps1` загружает конфигурацию в отдельную файловую базу `build/infobase`. `Test.ps1` добавляет демонстрационные данные и запускает проверки. Затем в окне запуска 1С выберите **Добавить → Добавление в список существующей информационной базы**, укажите каталог `build/infobase` и запустите **1С:Предприятие**.

Для установки платформы в нестандартном каталоге используйте параметр `-Platform`. Порядок сборки и выгрузки описан в [инструкции к сценариям](Кинотеатр/scripts/README.md).
