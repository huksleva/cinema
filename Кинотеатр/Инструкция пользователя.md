# Инструкция пользователя системы «Кинотеатр»

Версия конфигурации: **1.1.0**. Инструкция подготовлена **22 октября 2026 года**.

> Материалы действующей версии собраны в [комплекте 1.2.2](docs/1.2.2).

Система предназначена для учебного учета товаров кинобара: поступлений, продаж, розничных цен и остатков. В ней можно хранить фотографии товаров и формировать отчеты. Учет сеансов, мест в зале и бронирование билетов в эту версию не входят.

## 1. Что нужно для запуска

- Компьютер с установленной платформой **1С:Предприятие**. Проект проверен на учебной версии **8.3.27.1688 для Windows**.
- Распакованная папка проекта. Запускать базу непосредственно из ZIP-архива нельзя.
- Возможность записывать файлы в папку базы.

В учебной версии с одной информационной базой работает только один сеанс. Перед открытием Конфигуратора закройте режим «1С:Предприятие» этой базы, и наоборот.

## 2. Какой способ запуска выбрать

Если вы клонировали репозиторий с GitHub, выполните [сборку из исходников](../README.md#запуск-из-исходников). Варианты ниже относятся к локальному комплекту с готовой базой или файлами DT и CF.

### Вариант А. Открыть готовую папку базы

1. Скопируйте всю папку проекта на компьютер и распакуйте архив, если получили ZIP.
2. Откройте окно запуска 1С.
3. Нажмите **Добавить** и выберите **Добавление в список существующей информационной базы**.
4. Укажите название **Кинотеатр**.
5. Для базы, расположенной на данном компьютере, выберите каталог **infobase** внутри папки проекта. Указывать нужно папку, содержащую `1Cv8.1CD`, а не сам файл.
6. Завершите добавление и запустите базу кнопкой **1С:Предприятие**.

Файлы `Открыть Кинотеатр.cmd` и `Конфигуратор.cmd` также запускают базу относительно своей папки. В них указан путь к учебной платформе 8.3.27.1688 в стандартном каталоге. Если 1С установлена в другом месте, используйте добавление базы через окно запуска по шагам выше.

### Вариант Б. Восстановить базу из DT

Этот способ переносит конфигурацию, товары, фотографии, цены и документы вместе.

1. В окне запуска 1С создайте **новую пустую информационную базу**, без конфигурации.
2. Откройте ее в режиме **Конфигуратор**.
3. Выберите **Администрирование → Загрузить информационную базу**.
4. Укажите файл `Кинотеатр.dt` из комплекта.
5. Подтвердите загрузку и перезапуск, если платформа его предложит.
6. Закройте Конфигуратор и откройте эту базу в режиме **1С:Предприятие**.

**Загрузка DT заменяет содержимое целевой базы. Используйте новую пустую базу либо заранее сделайте резервную копию существующей.**

### Вариант В. Загрузить только конфигурацию из CF

1. Создайте новую пустую информационную базу и откройте Конфигуратор.
2. При необходимости выберите **Конфигурация → Открыть конфигурацию**.
3. Выберите **Конфигурация → Загрузить конфигурацию из файла** и укажите `Кинотеатр.cf`.
4. Выполните **Конфигурация → Обновить конфигурацию базы данных** и примите изменения.
5. Запустите базу в режиме **1С:Предприятие**.

**CF содержит структуру и код. Демонстрационные товары, фотографии, цены и документы в CF не входят.** Если нужен готовый пример для показа, используйте DT или папку `infobase`.

## 3. Разделы и права

При запуске открывается **Рабочее место кинобара**. На нем доступны кнопки **Новая продажа**, **Новый приход**, **Номенклатура**, **Покупатели**, **Организации**, **Цены**, **Отчет по продажам** и **Обновить остатки**. После записи документов нажмите **Обновить остатки**, чтобы обновить сводку. Оформление использует графитовую шапку и янтарные основные команды. В документах итог выделен отдельно и пересчитывается при изменении количества и цены.

В интерфейсе есть разделы **Покупка** и **Продажа**. Доступные команды зависят от назначенных пользователю ролей.

| Роль | Основное назначение |
| --- | --- |
| Покупка | Работа с поступлениями, номенклатурой и ценами |
| Продажа | Работа с продажами и покупателями, просмотр цен |
| Полные права | Доступ ко всем объектам и администрирование |

В поставке нет специально созданных постоянных учетных записей сотрудников. Их создает администратор в Конфигураторе и назначает нужные роли. Проверку работы под отдельными ограниченными профилями необходимо выполнить перед сдачей: автоматическая проверка входа под ними не была завершена.

## 4. Что находится в демонстрационной базе

- Организация: **Кинотеатр Премьера**.
- Покупатель: **Розничный покупатель**.
- Товары: **Попкорн соленый большой** и **Напиток 0,5 л**.
- В карточке попкорна сохранена фотография.
- Установлены розничные цены: **250 ₽** и **150 ₽**.
- Проведены приход и продажа.

| Товар | Поступило | Продано | Остаток | Выручка |
| --- | ---: | ---: | ---: | ---: |
| Попкорн | 100 шт. | 3 шт. | 97 шт. | 750 ₽ |
| Напиток | 50 шт. | 2 шт. | 48 шт. | 300 ₽ |
| Итого |  |  |  | **1050 ₽** |

Эти значения относятся к исходному демонстрационному сценарию. Если добавлять собственные документы, отчеты покажут новые итоги.

## 5. Подготовить справочники

### Организации

1. Откройте **Организации**.
2. Создайте организацию, укажите наименование и при необходимости ИНН.
3. Сохраните запись.

Организация обязательна в приходе и расходе. Остатки одной организации нельзя использовать для продажи от имени другой. Редактирование организаций предусмотрено для администратора.

### Покупатели

1. В разделе **Продажа** откройте **Покупатели**.
2. Создайте покупателя, заполните наименование и при необходимости телефон.
3. Сохраните запись.

Для обычной продажи можно использовать элемент **Розничный покупатель**.

### Номенклатура

1. В разделе **Покупка** откройте **Номенклатура**.
2. Нажмите **Создать**.
3. Укажите наименование товара и единицу измерения, например `шт`.
4. При необходимости загрузите фотографию.
5. Сохраните карточку стандартной командой записи.

## 6. Загрузить фотографию товара

1. Откройте карточку номенклатуры.
2. Нажмите **Загрузить фотографию**.
3. Выберите файл изображения, например JPG или PNG, который поддерживает платформа 1С.
4. Убедитесь, что фотография появилась в поле картинки.
5. **Сохраните карточку.** Выбор файла без записи карточки не завершает сохранение фотографии.
6. Закройте и повторно откройте товар, чтобы проверить результат.

Размер файла не должен превышать **5 МБ**. Изображение хранится внутри базы. После сохранения исходный файл не требуется для его показа в карточке.

Для замены фотографии повторите эти действия с новым файлом. Чтобы передать фотографии вместе с базой, используйте DT либо полную копию закрытой файловой базы.

## 7. Установить розничную цену

1. Откройте **Цены**.
2. Создайте запись.
3. Укажите **период**, **номенклатуру** и положительную **цену**.
4. Сохраните запись.

Для новой цены добавьте запись с более поздним периодом. Это сохраняет историю изменений. В продаже система выбирает последнюю действующую цену на дату документа.

Дата продажи должна быть не раньше периода нужной цены. Изменение регистра цен само по себе не пересчитывает уже проведенные продажи.

## 8. Оформить приход

1. В разделе **Покупка** откройте **Приход**.
2. Создайте документ.
3. Укажите дату и организацию.
4. В таблице **Товары** добавьте строки.
5. В каждой строке выберите номенклатуру, укажите положительное количество и закупочную цену.
6. Выполните стандартную команду **Провести** или **Провести и закрыть**.

При проведении система рассчитывает сумму каждой строки и увеличивает остаток выбранной организации. Простая запись черновика не изменяет остатки.

**Пример:** поступление 10 порций попкорна по 80 ₽ дает сумму строки 800 ₽ и увеличивает остаток на 10 штук.

## 9. Оформить продажу

1. В разделе **Продажа** откройте **Расход**.
2. Создайте документ.
3. Укажите дату, организацию и покупателя.
4. Добавьте товары и количество.
5. Для автоматического подбора цены оставьте в строке цену `0`. При проведении система возьмет ее из регистра **Цены** на дату документа. Можно указать положительную цену вручную.
6. Проведите документ.
7. Проверьте цену и сумму в сохраненном документе, затем обновите отчеты.

При проведении расход уменьшает остаток и записывает количество и выручку в регистр продаж. Если действующей цены нет, необходимо установить ее либо указать вручную. Продажа сверх текущего остатка отклоняется.

## 10. Посмотреть отчеты

### Остатки

Откройте отчет **Остатки** и нажмите **Обновить отчет**. Результат показывает текущие остатки по организациям и товарам.

### Продажи

Откройте отчет **Продажи** и нажмите **Обновить отчет**. Результат показывает количество проданных товаров и выручку по организациям и товарам за все время.

В этой версии в отчетах не реализован пользовательский выбор периода.

## 11. Исправить документ

Чтобы изменить количество, товар или цену, откройте документ, внесите изменения и повторно проведите его. Повторное проведение заменяет движения этого документа.

Для отмены проведенной операции используйте стандартную команду отмены проведения, если она доступна в форме или меню **Еще**. Отмена продажи возвращает товар в остаток. Отменить приход нельзя, если после этого текущий остаток станет отрицательным: сначала нужно исправить связанные продажи.

Контроль в этой версии проверяет текущий итог остатков. Он не проверяет всю последовательность исторических остатков при вводе документов задним числом. Для учебной демонстрации вводите операции в хронологическом порядке.

## 12. Частые сообщения

| Сообщение или ситуация | Что проверить |
| --- | --- |
| Укажите организацию | Заполните организацию в шапке документа |
| Добавьте хотя бы один товар | Внесите строки в таблицу Товары |
| Укажите товар и положительное количество | Выберите номенклатуру и задайте количество больше нуля в каждой строке |
| Цена должна быть больше нуля | Заполните закупочную цену; для продажи проверьте цену и ее период в регистре |
| Недостаточно товара | Проверьте организацию, проведенные поступления и остаток; уменьшите продаваемое количество |
| Фотография больше 5 МБ | Выберите файл меньшего размера |
| Изображение не загружается | Проверьте, что выбран исправный файл поддерживаемого формата |
| Нельзя открыть второй сеанс | Закройте другое окно этой учебной базы |
| Нет команды или доступа | Обратитесь к администратору для проверки назначенной роли |

## 13. Сделать резервную копию

1. Закройте режим **1С:Предприятие** этой базы.
2. Откройте ее в **Конфигураторе**.
3. Выберите **Администрирование → Выгрузить информационную базу**.
4. Сохраните DT в отдельное место с понятным именем и датой.

Резервная копия DT содержит конфигурацию и данные. Исходники в Git не заменяют резервное копирование данных.

## 14. Короткий сценарий показа преподавателю

1. Покажите разделы **Покупка** и **Продажа**.
2. Откройте карточку попкорна с фотографией.
3. Покажите приход 100 порций попкорна и 50 напитков.
4. Покажите продажу 3 порций попкорна и 2 напитков.
5. Сформируйте отчеты: остатки 97 и 48, выручка 1050 ₽, если демонстрационные данные не менялись.
6. Попробуйте провести расход сверх остатка и покажите отказ. Не сохраняйте эту попытку как рабочую продажу.
