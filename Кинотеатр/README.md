# Кинотеатр 1.2.2

Учебная конфигурация команды 1 для курса «Управление программными проектами». В системе есть панель управления, касса кинобара, рабочее место закупщика, учёт продаж и резервов товаров, касса билетов и справочники фильмов, залов, мест и сеансов.

## Запуск

- Для готовой базы разместите `1Cv8.1CD` в каталоге `database/` и запустите `Открыть Кинотеатр.cmd` или `Конфигуратор.cmd`.
- Для клона репозитория соберите отдельную базу и запустите проверки по [инструкции в корне](../README.md#запуск-из-исходников). Сценарий тестирования создаёт данные кинобара. Для показа билетной кассы укажите будущий сеанс и места зала либо откройте базу из комплекта.
