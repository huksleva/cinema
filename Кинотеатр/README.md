# Кинотеатр

Учебный проект команды 1 по курсу «Управление программными проектами». Версия 1.1.0.

Для начала откройте [Инструкцию пользователя](Инструкция%20пользователя.md). Порядок копирования и публикации исходников описан в файле [Передача проекта](Передача%20проекта.md).

Система учитывает товары кинобара кинотеатра. Есть справочники Номенклатура, Покупатели, Организации; документы Приход и Расход; регистр сведений Цены; подсистемы Покупка и Продажа; роли Покупка, Продажа, Полные права; регистры накопления ОстаткиТоваров и Продажи; отчеты Остатки и Продажи.

Проверено на учебной 1С 8.3.27.1688 под Windows. Другие сборки требуют проверки. Ограничения: нет учета сеансов и мест, фискализации и бухгалтерского учета. Проверяется текущий итог остатков, а не вся последовательность исторических остатков при заднем числе.

## Запуск

Для сборки из GitHub следуйте [инструкции по запуску из исходников](../README.md#запуск-из-исходников).

Если у вас есть локальный комплект с готовой базой `infobase`, используйте `Открыть Кинотеатр.cmd` или `Конфигуратор.cmd`. При запуске в режиме Предприятие открывается рабочее место кинобара.

При наличии файлов `Кинотеатр.dt` или `Кинотеатр.cf` используйте [инструкцию пользователя](Инструкция%20пользователя.md#2-какой-способ-запуска-выбрать) для восстановления базы или загрузки конфигурации.

Оформление «Графит и янтарь» описано в [документации по дизайну](docs/Дизайн.md).

## Демонстрация

1. Откройте Номенклатуру и товар «Попкорн соленый большой» с фотографией.
2. Посмотрите приход: попкорн 100 × 80, напиток 50 × 45.
3. Посмотрите расход: попкорн 3 × 250, напиток 2 × 150.
4. Отчет Остатки показывает 97 и 48. Отчет Продажи показывает выручку 1050.
5. Создайте продажу сверх остатка и убедитесь в отказе. Суммы рассчитываются при проведении, нулевая цена продажи заполняется из регистра на дату документа.

## Материалы

- `src/` — исходники выгрузки Конфигуратора в XML и BSL. Это **не проект EDT**.
- `docs/` — описание системы, инструкция, дизайн, тестирование, Agile/Scrum, Git и презентация.
- `tests/` — фактические журналы 21 автоматической проверки и синтаксического контроля.
- `scripts/` — сборка в отдельной базе, экспорт и запуск проверок.
- `assets/` — демонстрационная фотография и сведения об источнике.

## Совместная работа

Каждому участнику нужна собственная рабочая база. В Git храните src и документацию. Рабочая база, CF и DT исключены через `.gitignore`. Не редактируйте одновременно один объект метаданных без согласования. Рабочий процесс описан в `docs/Git.md`.

Удаленный репозиторий проекта — [huksleva/cinema](https://github.com/huksleva/cinema).

Полная автоматическая синхронизация GitHub с базой пока не настроена. Возможности EDT и существующих сценариев описаны в [docs/Автоматизация.md](docs/Автоматизация.md). Встроенное хранилище конфигурации учебная версия платформы не поддерживает.

## Проверки и приемка

14 проверок бизнес-логики и 7 проверок открытия форм и фотографии прошли. Временные тестовые пользователи удалены. Ограниченные профили не удалось проверить до штатного завершения, поэтому их проверка не засчитана. Нужно вручную проверить интерфейс, выбор фотографии мышью, операции под отдельными пользователями и восстановление DT на другом компьютере. Полный протокол находится в документации.
