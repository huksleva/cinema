# Как передать проект «Кинотеатр»

Локальный комплект можно перенести целиком или отправить архивом. Для совместной разработки используйте репозиторий GitHub.

## Передать готовый проект другому человеку

Передайте **Кинотеатр_комплект.zip**. Получателю нужно распаковать архив, открыть **Инструкция пользователя.md** и выбрать удобный способ запуска.

Вместо архива можно скопировать папку проекта целиком. Копировать файловую базу `infobase` нужно при закрытых сеансах этой базы 1С.

Для переноса работающей демонстрации достаточно `Кинотеатр.dt` и инструкции пользователя. DT содержит структуру, данные и фотографии. Получатель восстанавливает его в новой пустой базе 1С.

## Передать только конфигурацию

Передайте `Кинотеатр.cf`. В нем содержатся структура и программный код. Товары, фотографии и документы базы в CF не входят. Если получателю нужна готовая демонстрация, передайте DT.

## Продолжить разработку через Git

Клонируйте [huksleva/cinema](https://github.com/huksleva/cinema) через Git или GitHub Desktop. Рабочие файлы 1С находятся в папке `Кинотеатр` внутри репозитория. Сборка после клонирования описана в [корневом README](../README.md#запуск-из-исходников).

В репозиторий включаются:

- `src/` — метаданные XML, формы и модули BSL;
- `scripts/` — сборка, выгрузка и проверки;
- `assets/` — демонстрационное изображение и сведения об источнике;
- `tests/` — журналы выполненных проверок;
- файлы Markdown, включая инструкцию пользователя и описание проекта;
- `.gitignore` и `.gitattributes`.

Настроенный `.gitignore` исключает рабочую базу `infobase`, каталог сборки `build`, резервные копии, CF, DT, архив комплекта и экспортированные PDF, DOCX и PPTX из `docs/`. Документацию в Git можно читать в Markdown.

Каждый разработчик работает со своей копией репозитория и отдельной базой. Этот комплект использует формат выгрузки **Конфигуратора**, а не формат проекта EDT.

## Автоматизация

Полная автоматическая синхронизация базы с GitHub в этом комплекте **не настроена**. Есть сценарии сборки, выгрузки и тестирования. Для работы с файлами проекта без ручной выгрузки из Конфигуратора рассматривается переход на EDT после проверки совместимости с учебной платформой. Подробности находятся в [docs/Автоматизация.md](docs/Автоматизация.md).

## Что хранится в папке

| Файл или каталог | Назначение |
| --- | --- |
| Инструкция пользователя.md | Запуск и работа в системе |
| README.md | Краткое описание проекта и его границ |
| Кинотеатр.dt | Конфигурация и данные для восстановления |
| Кинотеатр.cf | Только конфигурация |
| infobase/ | Готовая файловая база |
| src/ | Текстовые исходники |
| scripts/ | Сценарии работы с исходниками и тестами |
| tests/ | Результаты автоматических проверок |
| docs/ | Документация, Git, автоматизация и презентация |
| assets/ | Демонстрационная фотография и лицензия |
