# Как передать проект «Кинотеатр»

## Проект для разработки

Клонируйте [huksleva/cinema](https://github.com/huksleva/cinema). Для сборки используйте исходники Конфигуратора в `Кинотеатр/src` и команды из [корневого README](../README.md#запуск-из-исходников). Каждый разработчик работает в отдельной базе.

В Git хранятся конфигурация XML и BSL, изображения интерфейса, документация версии 1.2.2 и журналы проверок. [Порядок работы с Git](docs/Git.md)

## Готовая база и резервные копии

Для переноса готового комплекта скопируйте файловую базу при закрытых сеансах. Разместите `1Cv8.1CD` в `Кинотеатр/database/` и откройте один из сценариев запуска. На этом компьютере в эту папку помещена база версии 1.2.2 из присланного архива.

Резервная копия `Kinoteatr_rezervkopia.dt` и бинарная конфигурация `Кинотеатр_рабочая_версия с дизайном.cf` хранятся локально в `backups/v1.2.2/`. Для восстановления DT создайте новую пустую базу и в Конфигураторе используйте **Администрирование → Загрузить информационную базу**. Для CF выполните **Конфигурация → Загрузить конфигурацию из файла**, затем обновите конфигурацию базы данных.

Файловые базы, журналы сеансов и резервные копии исключены из Git. Передавайте такие файлы согласованным способом вместе с [руководством версии 1.2.2](docs/1.2.2).
