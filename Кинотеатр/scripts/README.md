# Сценарии

Запускайте из PowerShell, используя разрешенный в вашей среде порядок выполнения сценариев. Не меняйте глобальную политику выполнения ради проекта.

```powershell
.\scripts\Build.ps1
.\scripts\Test.ps1
```

Build создает **отдельную** базу build/infobase. Исходники загружаются именно туда, рабочая infobase поставки не затрагивается. Платформа по умолчанию выбирается из стандартных каталогов; для воспроизводимости укажите явный путь:

```powershell
.\scripts\Build.ps1 -Platform 'C:\Program Files (x86)\1cv8t\8.3.27.1688\bin\1cv8t.exe'
```

`Test.ps1` заполняет базу сборки данными кинобара и запускает 14 проверок бизнес-логики и 8 проверок форм и сценариев. Журналы записываются в `build/logs`. Для показа билетной кассы с нуля добавьте фильм, зал с местами и будущий сеанс либо откройте информационную базу из комплекта.

Для экспорта изменений из своей базы:

```powershell
.\scripts\Export.ps1 -Database 'D:\MyCinemaDev'
```

Экспорт пишет в src. До запуска убедитесь, что нужные изменения сохранены в Git, а после проверьте diff. Не используйте параллельно одну базу: учебная платформа ограничивает подключения.

Сценарии не создают удаленный репозиторий, не отправляют исходники и не меняют настройки безопасности Windows. Не используйте тесты на рабочей базе с реальными данными.
