# Изменения версии 1.2.2

## Исправлено

- Отдельные команды панели управления открывают кассу кинобара и кассу билетов в соответствующих режимах.
- Цены товаров для кассы и формы бронирования берутся из регистра сведений «Цены». Если актуальная цена не задана, бронь не проводится; цена в форме бронирования недоступна для ручного изменения.
- Итог бронирования пересчитывается на сервере перед записью по строкам товаров.
- Отчёт «Доступность товаров» объединяет остатки и резервы, включая товар, который остался в резерве при нулевом складском остатке.
- Для документа «Расход» автоматически подставляются организация «Кинотеатр Премьера» и покупатель «Розничный покупатель», если они заведены в справочниках.
- Закупка из рабочего места проводится принудительно; ошибка проведения не должна показываться как успешная поставка.
- Единицы измерения вынесены в справочник; при открытии карточки старые строковые значения связываются с элементами справочника, а новые карточки получают значение «шт» по умолчанию.
- Для телефона покупателя используется маска ввода, сервер проверяет состав и длину номера; наименование покупателя подписано «ФИО».
- ИНН организации проверяется на 10 или 12 цифр.

## Требует подтверждения при приёмке

Проверка конфигурации 1С не заменяет запуск пользовательских сценариев. Перед сдачей проверьте вход под ролями «Покупка» и «Продажа», быструю закупку с последующим обновлением остатков, изменение цены в регистре, отображение резервов без складского остатка и значения по умолчанию в документе «Расход».

Учет фильмов, залов, сеансов и мест был указан в ответе на претензию как отдельная итерация, вне объёма базовой версии. Этот файл не объявляет эти функции завершёнными.
