Кинотеатр

Учебная конфигурация 1С:Предприятие для учёта товаров кинобара. Она ведёт поступления, продажи и цены, контролирует остатки по организациям и формирует отчёты по остаткам и выручке.

Перейти к запуску

Запуск из исходников

Понадобятся Windows, Git, PowerShell 7 и 1С:Предприятие. Сборка проверена на учебной платформе 8.3.27.1688.

git clone https://github.com/huksleva/cinema.git
Set-Location 'cinema\Кинотеатр'
.\scripts\Build.ps1
.\scripts\Test.ps1
  1. Build.ps1 создаёт отдельную базу в build/infobase. Test.ps1 добавляет демонстрационные данные и выполняет проверки.
  2. В окне запуска 1С выберите Добавить, затем Добавление в список существующей информационной базы.
  3. Укажите путь к каталогу Кинотеатр/build/infobase внутри клона и запустите 1С:Предприятие.

Если платформа установлена в нестандартном каталоге, передайте её путь обоим сценариям через параметр -Platform. Параметры сценариев

Работа в 1С

При обычном запуске открывается рабочее место кинобара. Доступ к командам зависит от роли пользователя.

Подготовить товары и цены

В справочниках заведите организацию, покупателя и товары. В карточке номенклатуры можно загрузить фотографию размером до 5 МБ. Сохраните карточку после загрузки. В разделе Цены укажите товар, период действия и положительную розничную цену.

Оформить поступление

Откройте Покупка → Приход, выберите организацию, добавьте товары, количество и закупочные цены. Проведите документ, чтобы увеличить остатки этой организации.

Оформить продажу

Откройте Продажа → Расход, выберите организацию и покупателя, затем добавьте товары и количество. Если оставить цену 0, система подберёт действующую цену на дату документа. При нехватке товара проведение отклоняется.

Посмотреть отчёты

В отчёте Остатки отображаются текущие остатки. Отчёт Продажи показывает проданное количество и выручку за всё время. Нажмите Обновить отчёт, чтобы получить актуальные данные.

Полная инструкция пользователя

Демонстрация

После запуска проверок откройте карточку попкорна с фотографией, затем проведённые документы прихода и продажи. Для исходных демонстрационных данных отчёты показывают следующие значения.

ТоварПриходПродажаОстатокВыручка
Попкорн100397750 ₽
Напиток50248300 ₽
Итого выручка1 050 ₽

Для проверки контроля остатков попробуйте провести продажу с количеством больше доступного.

Разработка и проверка

В каталоге Кинотеатр/src хранится выгрузка Конфигуратора с метаданными XML и модулями BSL. Для изменений создайте отдельную рабочую базу и ветку. После работы в Конфигураторе выгрузите конфигурацию в src, проверьте разницу и запустите сборку с тестами.

.\scripts\Export.ps1 -Database 'D:\MyCinemaDev'
git diff
.\scripts\Build.ps1
.\scripts\Test.ps1

Тесты проверяют проведение документов, цены, остатки, отчёты и открытие основных форм. Журналы нового запуска появятся в build/logs.
